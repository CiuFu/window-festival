## Window Festival changes — 2026-11-13

Window Festival is an independent derivative of [Window Sweaters][upstream]
by saragordic, based on [revision 6fc5811][base]. The original copyright
and attribution notices are preserved.

Window Festival adds nine knitted motifs, adjustable motif spacing, a local
pattern library and a stitch editor with live preview, undo and redo, and
reusable yarn palettes. It also adds portable pattern packages, application
identity and settings isolation, tests, and documentation. The window borders
reuse the upstream procedural yarn renderer. The workbench screenshot in
`docs/images/` shows Window Festival's native interface with built-in test data.
