# 本地图案库

入口：菜单栏 → **Pattern Library · 图案库…**。卡片显示实际针织渲染，支持全部、内置、我的图案筛选。

## 使用

- 点「新建图案…」从空白 12×12 网格开始，或选一张卡片后点「改针脚…」从样例开始。选线色、点击方格落针，右侧即时预览。
- 点右侧的底色色块，选好后点「应用底色」，网格和预览会一起更新。右侧还可以切换宽度预览。宽度预览用于比较效果，实际保存宽度在图案库中设置。
- 「图案用色」会列出画板上正在使用的颜色，点击即可复用。第一个色块是底色，可用来补回空白针脚。
- 点左侧当前画笔色块，选好后点「使用画笔色」，就可以落针。也可点右侧常用色直接换色，或按住 Option 点击格子取色。
- 要把新颜色留在色板，点「添加颜色…」，选好后点「添加到常用色」。新色块会同时成为当前画笔。进入「管理」后可以排序和删除色块，移除色块不会擦掉针脚。
- 左下角可撤销和重做落针和底色修改，也可用 ⌘Z 和 ⇧⌘Z。点「完成针脚」回到图案库，再保存和应用。
- 间距可选常用档位，再用箭头按 0.05 倍图案宽微调。宽度和原菜单共用 6 / 8 / 12 / 14 / 18 / 28 pt 六档；导入包原有的非预设值仍会保留。内置图案默认 28 pt 预览。
- 修改先保存在草稿中，预览不影响桌面。**保存副本并应用** 创建新图案，保留原版；没有修改时直接应用。离开有修改的草稿时会提示，**重置** 恢复所选图案。
- **导入图案包…** 接受 JSON 图案包，验证成功后加入“我的图案”，不立即切换桌面。
- 在「我的图案」选择图案后，可点「移到废纸篓…」。如果移除正在应用的图案，边框恢复 By App；内置图案不会提供这个按钮。
- **导出图案包…** 导出当前草稿，包含调整后的配置。文件可以离线传给别人，或在另一台电脑导入。
- 原 Pattern 菜单继续可用；我的图案按显示名称列在 Custom Patterns，选择时恢复包内宽度。菜单偏好保留当前选择和全局设置。

### 用文本编辑器制作

不需要额外工具。可以下载[晨雾雏菊](../examples/mist-daisy.knit.json)，或从应用导出一份自己的样例，用任意纯文本编辑器打开。改 `title` 后，试着改一行 `grid`：点号是底色，`a` 是 `palette` 第一种线色，`b` 是第二种，以此类推。每一行的长度必须等于行数。保存为 UTF-8 的 `.knit.json`，导入后在「我的图案」里先预览再应用。完整字段见下表。

如果用 AI 起草，可以把示例和下表一起交给它，例如：「沿用示例的格式，设计 12×12 的两色桂花针织图案，只返回 JSON。每行恰好 12 个字符，只用点号、a、b；间距 1.5，宽度 28。」导入后用针脚工作台检查和修改。

## 格式 v1

文件建议以 `.knit.json` 结尾，最大 64 KiB。顶层对象字段全部必需：

| 字段 | 约束 |
|---|---|
| kind | `window-festival-pattern` |
| version | 数字 `1`，不接受布尔值 |
| title | 1–40 个字符，UTF-8 少于 128 字节，无控制字符 |
| baseColor | `#RRGGBB` 底色 |
| palette | 1–15 个 `#RRGGBB` 线色 |
| grid | 4–14 行，列数等于行数；`.` 为底色，`a`–`o` 引用 palette，不能全部为空 |
| spacing | 有限数字 0–3，表示两个图案之间的额外空白宽度 / 图案宽度 |
| width | 有限数字 2–60，单位 pt |

网格从上到下、从左到右。所有颜色为不透明毛线；包不包含脚本、网络地址、外部资源路径或成品贴图。导入后的图案使用原版毛线曲线、光照和阴影。

## 存储与边界

`patterns.m` 先验证整个包，再写入隐藏的临时文件并移动到新文件名 `user-UUID.knit.json`。重复导入创建不同副本，不覆盖内置图案或已有文件。显示名称不参与文件路径拼接。

文件保存在 `~/Library/Application Support/Window Festival/charts`。`chart.c` 加载内置及原有 PNG 网格后，按文件名稳定排序追加有效包，按 name 恢复当前选择。无效文件、软链接和与已有图案同名的包会被跳过；界面导入的无效内容会显示原因。

图案表继续使用原来的 128 槽上限，包含 56 个内置图案、用户图案和运行时自动配色。达到容量时界面会提示。界面通过系统废纸篓移除用户图案包，不处理旧 PNG 图表。原有 PNG 网格仍通过原 Pattern 入口使用。

图案库和针脚工作台都在本机运行。工作台支持固定网格内逐格编辑；需要不同尺寸的网格时，可按下表编辑图案包。

## 验证与维护

- `make test` 包含包格式边界、九款图案往返、重复导入保护、重载保持选择、菜单宽度/偏好，以及草稿预览不改变当前图案像素/缓存。
- `make bin/library-ui-test && bin/library-ui-test` 会打开一个测试自己的原生窗口，临时目录完成针脚编辑、预设和微调、保存副本、应用、重复导入、移除及最小窗口滚动布局检查，随后关闭；不接触用户的图案目录或偏好。
- 文件选择/保存对话框使用 AppKit；尚未自动点击系统面板中的每一步。缩放/Space/鼠标穿透仍沿用原覆盖层的验收边界。

平台接口参考：[NSCollectionView](https://developer.apple.com/documentation/appkit/nscollectionview)、[NSOpenPanel](https://developer.apple.com/documentation/appkit/nsopenpanel)、[NSColorWell](https://developer.apple.com/documentation/appkit/nscolorwell)、[JSONSerialization](https://developer.apple.com/documentation/foundation/jsonserialization)。

系统废纸篓接口：[FileManager.trashItem](https://developer.apple.com/documentation/foundation/filemanager/trashitem(at:resultingitemurl:))。
