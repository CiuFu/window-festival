# 针织图案设计

图案与材质共用原版 `chart.c → knit.c` 路径。内置字符网格和用户 `.knit.json` 图案包都会解码成针脚颜色表，复用同一个渲染器。图案包还保存底色、间距、显示名称和建议宽度，详见[图案库规范](pattern-library.md)。

## 数据与选用

`chart.c` 的 `k_collection` 定义图案名称、从上到下的字符网格和 `a..f` 调色板。`.` 使用底色，每个字母使用对应颜色的毛线。当前九款：

| chart 名称 | 网格 | 内容 |
|---|---|---|
| festival-plum | 12×12 | 浅粉梅花、绿色枝叶 |
| festival-lantern | 14×14 | 红金灯笼、流苏 |
| festival-spring | 14×14 | 红底金色「春」字 |
| festival-daisy | 14×14 | 蓝底奶白雏菊、金黄花心 |
| festival-bamboo | 14×14 | 深绿底竹叶、浅色竹节 |
| festival-tulip | 14×14 | 米白底粉色郁金香 |
| festival-cloud | 14×14 | 藏蓝底奶金祥云 |
| festival-diamond | 14×14 | 青绿底金色菱花 |
| festival-persimmon | 14×14 | 暖棕底橙色柿子 |

`k_chart_styles` 为这九款设定独立 `base_color`、`upright` 和同色转角。原版图案的底色继续来自应用规则/取色。

Pattern 菜单使用已有 `chart=` 命令切换，保存在已有 `chart` / `patternByApp` 偏好中。选择 By App 恢复应用图案。新图案不改变全局 `g_knit.rows`；菜单暂时禁用 Stitch Size，尺寸通过 Border Width 调整。28 pt 时每格约 2 pt，12 pt 的文字辨识度较低。

已有自定义图表加载器保留，同名图表可替换内置网格并继承显示属性。文件中的像素是针脚颜色输入，不是最终边框贴图。新内置图案无需任何 PNG 资源。当前没有任意文字输入/字体转针脚编辑器；「春」是手工编排的样例。

## 渲染

`knit_make_tile` 使用原版 raised yarn 分支：毛线曲线、阴影、凹凸光照均保留。`upright` 图案采用与图表行数一致的方形针脚网格，在局部材质参数中设置，不覆盖用户的毛衣参数。缓存仍为原来的 64 槽 tile 缓存。

`knit_draw_faded` 沿用原来的圆角环裁剪、四边斜接和灰色/变暗处理。新图案在直边的全局坐标中正向重复，兼容原生窗口的 y-up 与离屏预览的翻转坐标；每边只容纳完整的方形图案，相邻图案额外留白由 `spacing` 决定，默认是边框宽度的 0.75 倍；整组居中排布，余量、间隙与圆角铺同色针织。图案按原尺寸绘制，不拉伸来填满边缘。极短的边容纳不下完整图案时只显示底色针织，避免半个字。原图案继续沿各条边旋转。

窗口几何、覆盖层、跟踪、移动、缩放与销毁没有新增路径。按窗口关闭不会清空共享图块；图案切换、图表重载和针脚设置变化沿用原缓存失效机制。图案库通过原有菜单命令应用全局图案。

## 图案库与草稿

`library.m` 通过 AppKit 卡片与配置面板展示正向、4–14 格方形图案。针脚工作台可从空白或样例编辑独立的网格副本；`knit_draw_pattern_preview` 直接调用共用的内部边框绘制函数，草稿图块用完释放，不占用已应用图案的缓存键、不修改全局图案表。

保存修改时创建新的 `.knit.json`，调用既有 `charts=reload` / `chart=` / `width=` 路径并保存菜单偏好。未修改时直接应用所选图案。导入只加入本地库，不立即更改当前桌面。导出的包可以在另一台电脑导入。

## 旧原型兼容

- 旧偏好 `theme=spring-festival` 首次读取时迁移到 `festival-lantern`，写入一次性迁移标记；后续以 Pattern 选择为准。
- 旧 CLI `theme=spring-festival` 映射到灯笼；`theme=sweaters` 映射到 By App。
- 不再读旧主题 JSON 和角饰素材；不删除用户目录内的旧文件。

继续添加花草或文字时，先设计低分辨率针脚网格并检查实际宽度的可读性。无需重建材质系统或引入新的图形依赖。
